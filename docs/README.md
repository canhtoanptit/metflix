# Webflix documentation

Start with the repository's [README](../README.md) to run a mode. Then:

| Document | For | What it covers |
| --- | --- | --- |
| [BLUEPRINT.md](BLUEPRINT.md) | Everyone, first | Scope and status, architecture, API surface, UX standard, rules for working in parallel |
| [FOUNDATION.md](FOUNDATION.md) | Anyone writing code | Workspace and commands, the contract and typed client, ports and their contract suites, conventions |
| [BACKEND.md](BACKEND.md) | Backend and web engineers | Running the API, behaviour the web app relies on, configuration, migrations, seeding, operations |
| [DECISIONS.md](DECISIONS.md) | Anyone changing the backend | Decision records D1 onwards: what was decided, why, and what it costs |
| [RECOMMENDATIONS.md](RECOMMENDATIONS.md) | Anyone changing browse | How rows, scores, badges, Continue Watching and popularity are computed |
| [CONTRACT_CHANGES.md](CONTRACT_CHANGES.md) | Web engineers | Append-only log of changes to `@webflix/contracts` |
| [KUBERNETES.md](KUBERNETES.md) | Operators of the `k8s` mode | The chart, images and kind workflow, measured behaviour, values, operations, production notes |
| [CLOUDFLARE.md](CLOUDFLARE.md) | Operators of the `cloudflare` mode | The Worker's design, caching, budgets and costs, local workflow, deploy runbook |
| [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) | Web engineers and designers | Identity, tokens, components, the row slider, the web app platform |
| [CREDITS.md](CREDITS.md) | Anyone shipping or showing Webflix | Every film, photograph and font with its licence (generated by `make content-credits`) |

Package guides: [e2e](../e2e/README.md) (browser suites, `make verify`),
[tools/smoke](../tools/smoke/README.md) (the conformance suite),
[tools/media](../tools/media/README.md) (the media pipeline),
[packages/player](../packages/player/README.md) (the video player).

## Which source is authoritative

When two documents seem to disagree, this one wins:

| Topic | Authoritative source |
| --- | --- |
| HTTP API (routes, schemas, error codes) | `packages/contracts/src/routes.ts` and its schemas; BLUEPRINT.md §6 summarises it |
| Who may do what (privileges) | BACKEND.md §3 |
| Rate-limit policies and their strict and relaxed values | BACKEND.md §3 |
| Environment variables | BACKEND.md §4 (portable and Node); CLOUDFLARE.md for the Worker's own; KUBERNETES.md §4 for chart values |
| Make targets | `make help` |
| Order and meaning of the verification suites | e2e/README.md and tools/smoke/README.md |
